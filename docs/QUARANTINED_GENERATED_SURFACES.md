# Quarantined generated surfaces

The former server mounted dozens of generic AI, robot, face/emotion, agentic device, and gap routes, including `gap-no-expense-optimizer-for-service-cancell`. They used generated chat output, sample data, ad hoc runtime tables, broad data access, and/or direct actions. Those files remain only as provenance pending an owner archive/delete decision; `backend/server.js` mounts none of them.

The supported service-cancellation optimizer is deterministic, evidence-versioned, profile-scoped, dependency/accessibility aware, approval-gated, receipt-based, and advisory. It neither claims a provider connection nor silently cancels a service.
